# 进化机制与自我升华 (AGENTS.md)

> **核心哲学**: 在 IntentOS 中，演化 (Evolution) 是 Agent 从“执行者”转变为“创造者”的过程。系统不只是在执行代码，而是在通过经验不断重塑自身。

---

## 1. 进化双环模型 (Dual-Loop Evolution)

IntentOS 的进化由两个相互嵌套的循环组成：

### 1.1 个体进化环 (Individual Loop)
*路径: 记忆 -> 冥想 -> 技能*
- **观察**: `ShadowAgent` 在会话结束时自动回顾，生成 `MemoryEntry`。
- **冥想**: `MeditationEngine` 定期整理碎片化记忆，解决冲突并提炼核心事实。
- **升华**: `Skillifier` 将高频出现的成功经验转化为受版本控制的 `Skill`。

### 1.2 系统演进环 (Systemic Loop)
*路径: 使用模式 -> 架构优化 -> 自举*
- **分析**: `UsagePatternAnalyzer` 实时监控 `IntentPipeline` 的执行效率。
- **优化**: `PipelineOptimizer` 根据模式分析结果，建议合并冗余阶段或拆分性能瓶颈。
- **自举**: 通过 `SelfBootstrapExecutor` 将架构调整固化为系统规则。

---

## 2. 关键进化组件

### 2.1 影子代理 (Shadow Agent)
每个进程都有一个“影子”。它不参与直接交互，而是作为审计者记录意图的达成度、LLM 的消耗以及用户潜在的满意度。

### 2.2 冥想引擎 (Meditation Engine)
冥想是系统在后台运行的异步进程。它利用 LLM 的高阶推理能力，对过去 N 次会话进行语义聚合（Semantic Merging），剔除噪音，提取真知。

### 2.3 技能提炼器 (Skillifier)
当某种行为模式被冥想引擎识别为“高价值”时，Skillifier 会自动生成 PEF 格式的技能定义，并将其注册到 `SkillStore`。

## 3. 进化指令集

Agent 可以通过以下语义指令参与进化过程：

| 操作码 | 作用 | 进化价值 |
| :--- | :--- | :--- |
| `QUERY MEMORY` | 检索历史经验 | 避免重复错误，利用过往知识 |
| `TRIGGER MEDITATION` | 手动触发深度思考 | 在处理复杂跨域问题后强制知识固化 |
| `DEFINE_INSTRUCTION` | 扩展系统指令 | 将进化的技能转化为原生 ISA |
| `MODIFY_PROCESSOR` | 调整执行策略 | 根据进化结果优化内核处理逻辑 |

---

## 4. 进化度量 (SLO for Evolution)

系统通过以下指标评估进化的成效：
- **技能转化率**: 从会话到新技能生成的比例。
- **架构压缩比**: 有机管道中被成功合并的冗余阶段数。
- **意图重用率**: 历史经验对新意图解析的贡献度。

---

## 5. 安全与约束 (Safety)

进化的边界受 `EvolutionPolicy` 约束：
- **无损原则**: 进化不得导致现有核心功能的退化或逻辑冲突。
- **人类确认**: 涉及系统级自举（Bootstrap）的架构优化建议默认需经过人类（PrivilegeLevel.ADMIN）确认。
- **遗忘机制**: 自动清理低频、陈旧且无进化价值的原始记忆以节省语义存储。

## 6. 路线图

- [ ] **跨 Agent 经验传播**: 实现 Agent 之间的知识社交传递。
- [ ] **模拟演化**: 在影子环境中预执行演化后的架构，评估性能提升后再应用。
- [ ] **多模态记忆提炼**: 支持从语音和图像日志中提取进化信息。

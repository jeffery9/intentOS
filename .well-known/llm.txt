description: |

# ==================== 核心概念 ====================

concepts:
  - name: 语义虚拟机 (Semantic VM)
    description: |
      LLM 作为处理器，自然语言作为"机器码"，PEF 作为可执行文件。
      语义 VM 是 IntentOS 的核心，它将自然语言意图编译为 LLM 可执行的 Prompt。
    keywords: [LLM, Prompt, PEF, 语义编译]
    
  - name: 意图奇点第一推动力 (IntentSingularity)
    description: |
      系统不主动产生自身意志，人类是唯一的“第一推动力（Prime Mover）”。
      奇点对象只读且被冻结，包含断言约束，作为分布式接力中的全局一致性绝对参照系。
    keywords: [第一推动力, 意图奇点, 现实坍缩器]
    
  - name: 万能语义阻抗匹配器 (_match_impedance)
    description: |
      在 Pipeline（|）级联中，利用 LLM 在运行时将上游非结构化文本动态清洗、
      提炼、坍缩为下游物理 Skill 所需的严格 JSON 参数，免去人类手写任何胶水代码。
    keywords: [阻抗匹配, 管道级联, 胶水代码, 参数对齐]
    
  - name: 常驻事件守护进程 (DaemonRunner)
    description: |
      事件驱动的操作系统常驻调度器，支持轮询网卡 Webhook、Cron 定时和物理文件 Watcher 触发，
      事件爆发时瞬间注入 Pipeline 首层 STDIN 激活 VM。
    keywords: [Daemon, 事件轮询, 守护进程, 触发器]
    
  - name: 分布式语义 P2P 网络
    description: |
      多节点全息集群。支持 PING/PONG 双向自发注册、技能 GOSSIP 病毒式传染实现全网认知对齐、
      以及 `relay_intent` 意图弹性接力将 Pipeline 步骤跨机器委托执行。
    keywords: [P2P, 路由表, Gossip 传染, 意图接力]
    
  - name: Loop 5 细胞凋亡与数字冥想
    description: |
      系统自发的去熵整理。在闲时启动 Meditation 分析技能重合度，通过大模型进行高维抽象合并，
      并对冲突或冗余的 Skill 进行物理注销与裁剪（Apoptosis），对抗生命系统的无限膨胀。
    keywords: [熵减, 数字冥想, 细胞凋亡, 技能合并]

# ==================== 快速开始 ====================

quick_start:
  install: |
    pip install pyyaml anyio
    
  run_shell: |
    PYTHONPATH=. python intentos/interface/shell.py
    
  run_api: |
    PYTHONPATH=. python intentos/interface/api.py
    
  code_example: |
    from intentos import SemanticVM, create_executor
    
    executor = create_executor(provider="openai", api_key="sk-...")
    vm = SemanticVM(executor)
    result = await vm.execute_program("my_program")

# IntentOS AI Discovery File
# 简洁版 AI 发现文件，便于快速理解

# ==================== 项目概述 ====================

IntentOS 是一个 AI 原生分布式操作系统（被称为“AI 时代的 UNIX”），将 LLM 视为"语义 CPU"，
将高维语义与自然语言意图视为驱动系统的第一性原理，彻底消灭接口和算力的阻抗。

核心理念：AI 时代的 UNIX · 语言即系统 · Prompt 即可执行文件 · 分布式语义 VM · 创世与凋亡双螺旋

# ==================== 核心创新 ====================

1. 语义虚拟机 (Semantic VM)
   - LLM 作为处理器，执行语义指令
   - PEF (Prompt Executable File) 是"机器码"
   - 支持 CALL、EXECUTE、以及系统元指令

2. 万能语义阻抗匹配器 (_match_impedance)
   - UNIX 级管道（|）级联：上游 STDOUT 智能流转为下游 STDIN
   - 自动阻抗匹配：大模型就地充当适配层，将非结构化文本动态清洗并强行坍缩为物理 Skill 强类型 JSON 参数字典

3. 常驻事件守护进程 (DaemonRunner)
   - 事件驱动执行：监听物理 Webhook、Cron 定时和文件 Watcher
   - 激发时自动加签不可篡改的人类“意图奇点 (IntentSingularity)”第一推动力，驱动流水线闭环

4. 分布式语义 P2P 网 (SemanticP2P)
   - 双向动态节点发现：全息节点的无感知广播注册
   - 智力社会化传染：新技能通过 Gossip 协议病毒式扩散，全网异步智商共振
   - 意图跨网接力：节点间管道指令弹性委托，算力与认知弹性分担

5. 细胞凋亡与数字冥想 (Apoptosis Loop)
   - Loop 5 自我熵减：系统在空闲时段运行 Meditation（数字冥想）
   - 重叠度判定：使用大模型评估技能冗余度并进行高维抽象合并
   - 细胞凋亡：对冗余/冲突规则执行物理注销与裁剪，实现系统自发熵减

# ==================== 架构层次 ====================

Layer 3: Application Layer (应用层)
  - CRM App / Sales App / BI App
  - 领域意图包 + 用户交互 + 结果呈现

Layer 2: Intent Layer (意图层)
  [L7] 意图解析 → 解析功能意图 + 操作意图
  [L6] 任务规划 → 生成任务 DAG + Ops Model
  [L5] 上下文收集 → 多模态事件图
  [L4] 安全验证 → 权限校验 + Human-in-the-loop
  [L3] 能力绑定 → 绑定能力调用
  [L2] 执行 → 分布式调度执行
  [L1] 改进 → 意图检测 + 自动修复与阻抗匹配

Layer 1: Model Layer (模型层)
  - OpenAI / Anthropic / Ollama
  - 语义 CPU: 理解/推理/生成

# ==================== 快速开始 ====================

安装:
  pip install pyyaml anyio

启动 Shell:
  PYTHONPATH=. python intentos/interface/shell.py

启动 API:
  PYTHONPATH=. python intentos/interface/api.py

Python 代码:
  from intentos import SemanticVM, create_executor
  executor = create_executor(provider="openai")
  vm = SemanticVM(executor)
  result = await vm.execute_program("my_program")

# ==================== 核心概念 ====================

语义 CPU:
  LLM 作为处理器，理解并执行自然语言指令

意图奇点 (IntentSingularity):
  冻结的、人类唯一的不可篡改意图第一推动力，系统现实坍缩器

万能语义阻抗匹配:
  用 LLM 抹平上下游节点的数据协议阻抗，实现零胶水代码级联

Gossip 技能传染:
  新进化出的技能在 P2P 网络中自发广播，自动对齐整个集群的认知

数字冥想与凋亡:
  系统自发的夜间整理行为，合并冗余技能并删除冲突代码，对抗系统膨胀
